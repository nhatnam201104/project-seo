Danh sách API — Website bán mắt kính

REST API cho ProjectSale. Base path /api/v1, JSON, xác thực JWT. Tên trường đồng bộ với schema (18 bảng). Đánh dấu quyền và mức ưu tiên Must/Should.

PUBLIC Không cần đăng nhập USER Cần JWT user ADMIN Cần JWT role ADMIN MUST MVP SHOULD Nên có

Quy ước chung

  • Base path: /api/v1 — mọi endpoint đứng sau tiền tố này.
  • Kiểu dữ liệu: Request/Response JSON (Content-Type: application/json), charset UTF-8.
  • Xác thực: JWT Bearer trong header Authorization: Bearer <access_token>. Access token ngắn hạn + refresh token.
  • Phân quyền: role trong JWT (USER/ADMIN). Endpoint Admin bắt buộc role ADMIN.
  • Phân trang: ?page=0&size=20&sort=field,asc|desc (Spring Pageable). Response bọc content, totalElements, totalPages, number, size.
  • ID public: mọi trường id, *_id và query ID trong API là UUID; BIGINT chỉ dùng nội bộ trong database.
  • Lọc/tìm kiếm: query params (vd ?categoryId=&brandId=&minPrice=&maxPrice=&color=&q=).
  • Định danh công khai: tài nguyên SEO dùng slug; đơn hàng dùng order_code (không lộ id tuần tự).
  • Tiền tệ: số nguyên/thập phân VND theo DECIMAL(12,2); thời gian ISO-8601.
  • Idempotency: tạo đơn nên gửi khoá idempotency để tránh double-submit.

Mã lỗi & HTTP status code

CodeÝ nghĩaDùng khi
200 OKThành côngGET/PUT/PATCH thành công.
201 CreatedĐã tạoPOST tạo tài nguyên (đơn, user, review...).
204 No ContentThành công không bodyDELETE, logout.
400 Bad RequestDữ liệu sai/không hợp lệValidate lỗi, mã giảm giá không hợp lệ.
401 UnauthorizedChưa xác thựcThiếu/hết hạn JWT.
403 ForbiddenKhông đủ quyềnUSER gọi endpoint ADMIN.
404 Not FoundKhông tìm thấySlug/order_code không tồn tại.
409 ConflictXung độtEmail trùng, oversell (optimistic lock), sku trùng.
422 UnprocessableNghiệp vụ từ chốiHuỷ đơn không PENDING, tồn kho không đủ.
429 Too Many RequestsQuá tần suấtRate-limit login.
500 Server ErrorLỗi hệ thốngNgoại lệ không mong đợi.

Body lỗi chuẩn: { "timestamp", "status", "error", "code", "message", "path" }.
